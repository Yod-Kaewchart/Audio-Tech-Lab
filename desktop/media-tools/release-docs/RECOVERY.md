# กู้คืนการเลือกโฟลเดอร์ (สำหรับผู้ดูแล)

เมื่อ guard.release() ยืนยันการปลด guard ไม่สำเร็จ แอปแสดงการเลือกโฟลเดอร์ต้องกู้คืน และ cleanup-required ไม่เริ่ม Download/Convert หรือการตรวจต้นทางใหม่ ไม่ใช้การเปิดแอปใหม่หรือการไม่มี staging เป็นหลักฐานว่าปลอดภัย

ไม่มีกลไกล้างสถานะอัตโนมัติในรุ่นนี้ ต้องยืนยันรายการต่อไปนี้ก่อนคืนการใช้งาน:

1. ปิดทุก instance ของ Audio Tech Labs Media Tools ตรวจ Task Manager/Process Explorer ว่า app, ProcessHost และ process ต้นไม้ของงานจาก vendor (ffmpeg, ffprobe, yt-dlp, node) ของ instance นั้นหยุดครบแล้ว อย่าหยุด process ของโปรแกรมอื่นเพียงเพราะชื่อเหมือนกัน เก็บ PID, executable path และเวลาสิ้นสุดไว้เป็นหลักฐาน ถ้ายังยืนยันไม่ได้ ให้คงสถานะบล็อก
2. สำรอง `%APPDATA%\Audio Tech Labs Media Tools\local-media\current-job.json` อ่าน recovery.folderPath และตรวจโฟลเดอร์นั้นด้วย identity/permissions เดิม ตรวจเฉพาะ `.atl-write-check-*` ที่การเลือกโฟลเดอร์นี้สร้างไว้ หากไม่แน่ใจเจ้าของไฟล์ ห้ามลบ ตรวจการปิด handle และล้างเฉพาะไฟล์ check ที่พิสูจน์ว่าเป็นของการทดสอบนี้ เก็บหลักฐาน ไม่แตะไฟล์เสียง/ไฟล์อื่น
3. ยืนยันว่า process หยุดครบ โฟลเดอร์เข้าถึงได้ ปลด handle ครบ และไม่มี check ที่ค้างจากงานนี้ เมื่อครบแล้วและแอปปิดอยู่ จึงย้ายเฉพาะ current-job.json ไปยังสำเนากู้คืนที่เก็บไว้ (ห้ามลบทั้ง profile) เปิดแอปใหม่และเลือกโฟลเดอร์อีกครั้ง หากเกิดซ้ำให้หยุดและเก็บหลักฐานใหม่

หากการเขียน recovery ลงดิสก์ล้มเหลว จะมีข้อความบันทึก recovery ไม่สำเร็จ ในกรณีนี้ต้องตรวจ process/โฟลเดอร์ด้วยตนเองตามรายการข้างต้นก่อนเปิดแอปใหม่ แม้ไม่มี record บนดิสก์

คู่มือนี้ไม่อนุญาตให้ข้ามการตรวจ process/cleanup หรือใช้การลบ state เป็นขั้นตอนแรก
